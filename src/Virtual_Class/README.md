# 추상 클래스(Virtual Class)

**추상(Abstraction)**: **여러가지 사물이나 개념**에서 **공통되는 특성이나 속성** 따위를 추출해 파악하는 작용

### 특징
  1. 추상 클래스 앞에 **abstract**키워드 붙여 선언
  2. 추상 메서드 포함.
     - **추상 메서드**: 메서드의 시그니처만 선언, 어떤 동작하는지 내용 정의x -> 추상 클래스 상속받은 클래스는 추상 메서드 오버라이딩해서 동작 구현해야 함.
  3. 추상 클래스는 new 키워드 사용해서 객체 생성x
  4. 추상 클래스는 추상 메서드/일반 메서드 o

```
// 형식
[접근_제한자] abstract class 클래스명 {
  // 필드
  // 일반 메서드
  abstract 반환형 메서드명(매개변수1, 매개변수2...); // 추상 메서드
}
```

### 사용하는 이유
1. 코드 가독성 제고
2. 효율성, 생산성 향상
   - 부모 클래스(추상 클래스) 메서드 오버라이딩함
